# Code of Conduct

DEPict adopts the [Contributor Covenant](https://www.contributor-covenant.org/), v2.1.

In short: be kind, be respectful, assume good faith, and help make this a welcoming
community for people of every background and experience level. Harassment,
discrimination, and abusive behavior are not tolerated.

Report concerns to the maintainers at **conduct@depict.example** (replace with a real
address before public release). Reports will be handled confidentially.

The full text of the Contributor Covenant v2.1 governs this project and can be read at
https://www.contributor-covenant.org/version/2/1/code_of_conduct/.
